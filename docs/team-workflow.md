# Team Workflow

## Branch Naming

```text
feature/기능이름
fix/수정내용
docs/문서내용
```

## Commit Message Examples

```text
Add login page
Add user API
Fix header layout
Update project README
```

## Pull Request Checklist

- 작업 내용이 명확한가?
- 실행 방법이 README에 반영되었는가?
- 비밀번호, API key, DB 정보가 포함되지 않았는가?
- 충돌이 없는가?

## Suggested Responsibilities

```text
frontend: React 화면과 API 연동
backend: Spring Boot API, DB, 인증/인가
ai-server: FastAPI 기반 AI/추천/분석 기능
docs: 회의록, 요구사항, API 명세
```
